VI and MCMC with iTarFlow

Metis’s Normalising Flow surrogate provides an exact likelihood, enabling us to use it in-place of our simulator/data-generating processes’s likelihood function in standard inference pipelines.

Tip

Conceptually, we imagine that our true data-generating process, has some underlying likelihood \(p^{*}(x|\theta)\), which is impractical to evaluate or otherwise inaccessible. In its place we are substituting the likelihood associated with our surrogate \(\hat{p}(x|\theta)\) and hope that our surrogate has been trained sufficiently well that \(\hat{p}(x|\theta)\approx p^{*}(x|\theta)\).

Run the commands from the repository root in a terminal, or download this page as a notebook into examples/ and run its cells. The setup cell below switches to the repository root. In a terminal, omit the notebook-only %%bash lines.

Preparing an observation

For this tutorial we’ll generate our observation from our SIRDS simulator. We infer the initial infected fraction \(I_0\), beta, gamma and omega, treating only the mortality rate as known.

TRUE_I0 = 0.02
TRUE_BETA = 0.45
TRUE_GAMMA = 0.12
TRUE_OMEGA = 0.025
TRUE_MU = 0.01

S_obs, I_obs, R_obs, D_obs = simulate_sirds(
    I0=TRUE_I0, beta=TRUE_BETA, gamma=TRUE_GAMMA, omega=TRUE_OMEGA,
    mu=TRUE_MU, T=cfg.dataset.num_timesteps, seed=999,
)
y_obs_raw = np.stack([S_obs, I_obs, R_obs, D_obs], axis=-1)[1:]  # drop t=0
y_obs = torch.as_tensor(y_obs_raw, dtype=torch.float32, device=DEVICE)
y_obs = ((y_obs - series_mean) / series_std).unsqueeze(0)

Choosing the prior

We’ll assume independent uniform priors: \[ \begin{align} &I_0 \sim \mathcal{U}(0.01, 0.1)\\ &\beta \sim \mathcal{U}(0.2, 0.8)\\ &\gamma \sim \mathcal{U}(0.05, 0.3)\\ &\omega \sim \mathcal{U}(0.005, 0.05) \end{align} \]

The inference problem

Given our observation \(x'\), our choice of priors \(p(\theta)\) and our trained surrogate we have an unnormalised posterior density,

\[ p(\theta|x=x') \propto \hat{p}(x=x'|\theta)p(\theta) \]

To obtain samples from the posterior we need to either fit a parametrised distribution or run MCMC.

Variational Inference

We introduce a parametrised distribution \(q_{\phi}\), in this case a multivariate Gaussian transformed to lie within the parameter bounds, and maximise the Evidence Lower Bound (ELBO): \[ \max_{\phi}\;\mathbb{E}_{\theta\sim q_{\phi}(\theta)}[\log \hat{p}(x=x'|\theta)] - \mathrm{KL}[q_{\phi}(\theta)\,\vert\vert\,p(\theta)] \]

Note

This is equivalent to minimising the reverse KL-divergence between \(q_{\phi}\) and the posterior.

We implement this in code using PyTorch’s distributions module.

import math
import torch.nn.functional as F
import torch.distributions as dist

PARAM_BOUNDS = {
    "I_0": (0.01, 0.1),
    "beta": (0.2, 0.8),
    "gamma": (0.05, 0.3),
    "omega": (0.005, 0.05),
}
lo = torch.tensor([b[0] for b in PARAM_BOUNDS.values()], device=DEVICE)
hi = torch.tensor([b[1] for b in PARAM_BOUNDS.values()], device=DEVICE)

DATA_DIM = y_obs[0].numel()

n_params = len(PARAM_BOUNDS)
q_mu = nn.Parameter(torch.zeros(n_params, device=DEVICE))
q_L_flat = nn.Parameter(torch.zeros(n_params * (n_params + 1) // 2, device=DEVICE))

def build_q():
    L = torch.zeros(n_params, n_params, device=DEVICE)
    idx = torch.tril_indices(n_params, n_params, device=DEVICE)
    L[idx[0], idx[1]] = q_L_flat
    diag_idx = torch.arange(n_params, device=DEVICE)
    L[diag_idx, diag_idx] = F.softplus(L[diag_idx, diag_idx]) + 1e-4

    base = dist.MultivariateNormal(q_mu, scale_tril=L)
    transforms = [dist.SigmoidTransform(), dist.AffineTransform(loc=lo, scale=(hi - lo))]
    return dist.TransformedDistribution(base, transforms)

with torch.no_grad():
    centre = (lo + hi) / 2
    q_mu.copy_(torch.logit((centre - lo) / (hi - lo)))

print(f"Initial q centre (constrained): {build_q().sample().detach().cpu().numpy()}")

Now the objective:

def make_conditioning(theta_samples):
    fixed = torch.ones_like(theta_samples[:, 0])
    values = {
        "I_0": theta_samples[:, 0],
        "beta": theta_samples[:, 1],
        "gamma": theta_samples[:, 2],
        "omega": theta_samples[:, 3],
        "mu": TRUE_MU * fixed,
    }
    full_params = torch.stack(
        [values[name] for name in cfg.dataset.surrogate_input_variables],
        dim=1,
    )
    return (full_params - input_mean) / input_std


def compute_log_likelihood(y, theta_samples):
    n_mc = theta_samples.shape[0]
    full_params = make_conditioning(theta_samples)
    y_batch = y.expand(n_mc, -1, -1)

    z, total_logdet_scaled = nf(y_batch, full_params)

    log_pz = -0.5 * z.reshape(n_mc, -1).pow(2).sum(dim=1) \
             - 0.5 * DATA_DIM * math.log(2 * math.pi)
    true_logdet = DATA_DIM * total_logdet_scaled
    return log_pz + true_logdet


def compute_elbo(n_mc=32):
    q = build_q()
    theta_samples = q.rsample((n_mc,))
    theta_clamped = torch.stack([
        theta_samples[:, i].clamp(lo[i] + 1e-6, hi[i] - 1e-6)
        for i in range(n_params)
    ], dim=1)

    log_lik = compute_log_likelihood(y_obs, theta_clamped)
    log_q = q.log_prob(theta_clamped)
    log_prior = -torch.log(hi - lo).sum()

    return (log_lik + log_prior - log_q).mean()

Finally, we optimise

nf.eval()

vi_optimizer = torch.optim.Adam([q_mu, q_L_flat], lr=0.02)
n_vi_steps = 1500
n_mc = 32
elbo_history = []

for step in range(n_vi_steps):
    vi_optimizer.zero_grad()
    elbo = compute_elbo(n_mc=n_mc)
    (-elbo).backward()
    torch.nn.utils.clip_grad_norm_([q_mu, q_L_flat], max_norm=5.0)
    vi_optimizer.step()
    elbo_history.append(elbo.item())

    if step % 100 == 0 or step == n_vi_steps - 1:
        with torch.no_grad():
            q = build_q()
            mean_c = q.sample((1000,)).mean(dim=0)
        means = ", ".join(
            f"{name}={mean_c[i]:.4f}" for i, name in enumerate(PARAM_BOUNDS)
        )
        print(f"Step {step:4d}  ELBO={elbo.item():10.1f}  q_mean=[{means}]")

            ax.axhline(true_vals[i], color="red", lw=1, ls="--")

MCMC

We can also sample from the same surrogate-based posterior using Pyro’s No-U-Turn Sampler (NUTS), an adaptive Hamiltonian Monte Carlo method. We reuse the uniform priors, observation, and compute_log_likelihood above; the mortality rate remains fixed.

Pyro is optional. Install it into the project’s environment before continuing (the package is named pyro-ppl, but imported as pyro):

%%bash
uv pip install pyro-ppl

Each pyro.sample declares a parameter’s prior. pyro.factor adds the surrogate log-likelihood to the joint log density. Pyro handles the transforms between bounded parameters and the unconstrained space used by NUTS. Keep gradients enabled through the surrogate, just as for VI.

import pyro
import pyro.distributions as pyro_dist
from pyro.infer import MCMC, NUTS

pyro.set_rng_seed(42)

def posterior_model():
    theta = torch.stack([
        pyro.sample(name, pyro_dist.Uniform(lo[i], hi[i]))
        for i, name in enumerate(PARAM_BOUNDS)
    ])
    log_lik = compute_log_likelihood(y_obs, theta.unsqueeze(0))[0]
    pyro.factor("surrogate_likelihood", log_lik)

Warmup adapts the step size and mass matrix, and its draws are discarded. We use a full mass matrix to accommodate correlations between the parameters. This example runs one chain for straightforward notebook execution.

kernel = NUTS(posterior_model, full_mass=True, target_accept_prob=0.8)
mcmc = MCMC(kernel, warmup_steps=500, num_samples=1000, num_chains=1)
mcmc.run()
mcmc.summary(prob=0.95)

mcmc_draws = mcmc.get_samples()
theta_mcmc = torch.stack([mcmc_draws[name] for name in PARAM_BOUNDS], dim=1)
mcmc_samples = theta_mcmc.detach().cpu().numpy()

Inspect the effective sample sizes, divergences, and trace plots before interpreting the posterior. The single-chain summary uses a split-chain R-hat; it does not replace checking agreement across independently initialized chains. Increase warmup or sampling length if mixing is poor.

MCMC posterior predictive check

Finally, draw trajectories conditional on samples from the MCMC posterior, using the same conditioning and inverse normalization as for VI.

with torch.no_grad():
    selected = torch.randperm(theta_mcmc.shape[0], device=theta_mcmc.device)[:10]
    conditioning = make_conditioning(theta_mcmc[selected])
    z_rand = torch.randn((len(selected), *y_obs.shape[1:]), device=DEVICE)
