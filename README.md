# metis

An easy-to-use package for ABM timeseries surrogate modelling.  


## Install

With [uv](https://docs.astral.sh/uv/) installation is

```
uv sync
```

If you'd like to contribute then make sure pre-commit hooks are installed and use

```
uv sync --dev
```
